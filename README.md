## About me

I'm a software developer who likes turning ideas into real products.

Most of the time, I'm working with **Python**, **TypeScript**, **React**, **Flutter**, and sometimes **C** when the project gets closer to hardware.

I enjoy building things that actually solve problems — whether that's a backend API, a mobile app, a computer vision system, or an IoT solution.

A few things that describe me well:

- I like building complete solutions, not just isolated features
- I move comfortably between backend, frontend and mobile
- I have a strong interest in applied AI and computer vision
- I also enjoy embedded systems, IoT and distributed solutions
- I care about making software useful, functional and clean
